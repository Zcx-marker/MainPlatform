设备设定界面 · 按钮/控件 → 业务逻辑映射
基于 MainPlatform（键合机控制平台）XAML 与截图反推 · 示意结构
已绑定命令（实现被 SafeNet 加密，未读到） 有控件无绑定（ViewModel 空壳） 参数输入框（硬编码值，未绑定）
顶部工具栏（主窗口，全局）
打开程序 → 文件选择 → 加载配方(.ini) → 解析并回填全部界面参数 → 更新程序名/顺序号
另存程序 → 当前参数快照另存为新配方文件（防覆盖原配方）
统计 → 打开产量/不良/稼动统计视图
退出登录 → 二次确认 → 清理会话/权限 → 返回登录页
模式页（键合头搜索 · 线夹 · 功能开关）
数据流：加载配方 → 回填参数框 → 修改后点「保存参数」→ 范围校验 → 写回配方/下发控制器
搜索参数（Z 轴找焊盘过程）
初始压力 20g(5~150)：搜索开始时的接触压力基准
触发距离 20um(10~100)：判定接触后到触发焊接的下压距离
释放距离 20um(10~100)：焊点成形后线夹释放/抬升距离
复位高度 800um(100~10000)：搜索/焊接完成后 Z 轴复位高度
搜索阈值 20um(0~20)：判定"已接触焊盘"的阈值
搜索范围 200um(100~500)：搜索行程上限（防撞）
搜索速度 5%(1~100)：慢速下探找接触点的速度
搜索压力 20g(5~100)：搜索过程施加的压力
线夹参数（夹持金线机构）
打开力 150%(0~500)：线夹张开力度
夹紧力 300%(0~500)：夹紧力度，决定夹线可靠性
断丝力 300%(0~500)：拉断尾丝的力
开关缓冲 35ms(0~50)：开/关动作缓冲，减小冲击
功能开关（布尔位 → 写配方位）
脚踏功能反向：脚踏触发逻辑取反
焊接时关闭线夹：焊接过程保持线夹闭合防位移
焊前打火：焊前打火成球(FAB)
自动压球使能（手动模式有效）：自动压球功能开关
恢复默认（XAML 已注释） → 确认框 → 恢复出厂默认参数（改动前应备份当前值）
保存参数（XAML 已注释） → 逐项范围校验 → 写回配方文件 → 按需下发运动控制器生效
校准测试页（运动参数 + 校准操作）
焊接速度 200%(5~500)：焊接动作速度
断丝速度 10%(5~1000)：断丝动作速度
打火速度 300%(0~1000)：打火机构动作速度
加热功率 0%(0~100)：加热台功率
留尾模式（线夹/气流/关闭）：尾丝长度控制方式
校准操作（7 个橙色按钮，均为动作型）
水平锁紧 → 锁/解锁 XY 工作台机械锁（校准时固定台面）→ 更新锁紧状态指示
垂直锁紧 → 锁/解锁 Z 轴 → 更新锁紧状态指示
力校准 → 引导放置标准砝码 → 采集力传感器读数 → 修正增益/偏移 → 标记"已完成"
力测试 → 施加已知力 → 对比显示读数偏差 → 判定合格/超差
超声校准 → 校准超声换能器功率/频率 → 标记"已完成"
初始化 → 各轴回零/参数复位 → 安全确认（防撞）
序列号 → 读取/写入设备序列号 → 更新"未配置"状态
恢复默认 → 确认 → 恢复默认运动参数
保存参数 → 范围校验 → 写回配方/控制器
状态区：力校准✅/超声校准✅/序列号⚠未配置 → 由校准记录驱动，非硬编码
计划管理页（顺序号 ↔ 配方文件绑定）
核心机制：生产时按「顺序号」自动加载对应 csv 参数文件，本页维护这套 序号→文件 绑定关系
另存为 → 当前顺序号文件(.ini)导出/另存 → 路径更新
解绑（每行） → 解除该序号与文件的绑定 → 行变"-"、按钮禁用
解绑所有 → 二次确认 → 清空全部绑定 → 刷新列表
绑定列表 序号0~8：显示 csv 文件路径；未绑定显示"-"且解绑禁用
